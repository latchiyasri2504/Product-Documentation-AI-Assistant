# Baseline Model Testing

## 1. Introduction

Baseline testing is performed to understand the initial performance of the selected Small Language Model before applying any fine-tuning or optimization.

## 2. Selected Model

Model Name: Qwen2.5-0.5B-Instruct

Model Type: Instruction-Tuned Small Language Model

## 3. Testing Prompts

The following questions will be used to test the model.

1. What is a laptop?
2. How do I charge a laptop?
3. How can I improve laptop battery life?
4. How do I connect to Wi-Fi?
5. How do I restart a laptop?

## 4. Evaluation Criteria

The model will be evaluated based on:

- Answer accuracy
- Relevance
- Clarity
- Response time
- Output quality
